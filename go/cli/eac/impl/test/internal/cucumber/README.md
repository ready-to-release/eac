# cucumber

Provides Cucumber JSON report parsing, grouping, filtering, and rendering for BDD test result display. Converts Cucumber report data into formatted markdown summaries.

## Key Types

- **`CucumberReport`** -- Slice of `Feature` entries representing a full Cucumber JSON report
- **`Feature`** -- A Gherkin feature with URI, name, description, tags, and scenario elements
- **`Scenario`** -- A scenario within a feature (includes `before`/`after` hooks and steps)
- **`Step`** -- A scenario step with keyword, name, match info, and result
- **`StepResult`** -- Execution result for a step (status, duration, error message)
- **`ScenarioWithFeature`** -- Pairs a scenario with its parent feature for grouped display
- **`GitContext`** -- Interface for providing git repository URL context to rendered links

## Key Functions

- **`ParseFile()`** -- Load and parse a Cucumber JSON report from a file
- **`GroupByFeature()`** -- Group scenario results by their parent feature
- **`FilterByVerificationType()`** -- Filter scenarios by verification type tags (e.g., L0, L1, L2)
- **`GroupScenariosByRule()`** -- Group scenarios by Gherkin Rule blocks within features
- **`RenderTestSummary()`** -- Render a markdown summary table of test results
- **`RenderAllFeatures()`** -- Render all feature results as formatted markdown
- **`RenderByVerificationType()`** -- Render results grouped by verification type
- **`RenderAppendixA()`** -- Render Appendix A showing feature file contents with source links

## Patterns

- Model-render separation: `model.go` and `parser.go` handle data, `renderer.go` and `appendix.go` handle display
- Verification type filtering: uses `@L0`, `@L1`, `@L2` tags to categorize tests by level
- Git-aware rendering: uses `GitContext` interface to generate source links in markdown output

## Internal Structure

| File | Responsibility |
| --- | --- |
| model.go | Cucumber report data types with JSON serialization and convenience methods |
| parser.go | JSON parsing, feature grouping, verification type filtering, and rule grouping |
| renderer.go | Markdown rendering for test summaries, feature results, and verification type views |
| appendix.go | Appendix A rendering with feature file content display and git source links |

## Dependencies

- `core/logging` -- structured logging

## Role in System

The `cucumber` package is the BDD test result processing layer. It parses Cucumber JSON reports generated by godog test runs, then provides grouping and rendering capabilities used by `show test-summary`, `show test-results`, and report generation commands.
