## Common Workflows

### Feature Development

1. [Create workspace](./create-feature-workspace.md) for your feature
2. Make code changes
3. [Commit with AI](./make-commits-with-ai.md) for semantic messages
4. [Create pull request](./create-pull-request.md) for review
5. [Merge back to main](./merge-workspace-changes.md)

### Parallel Development

- Work on multiple features simultaneously using separate workspaces
- Switch between features without branch conflicts
- Merge each feature independently
