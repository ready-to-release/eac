# Changelog

Changelog format and versioning conventions for repository-level and module-level change documentation.

## Overview

The repository uses [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format with [Semantic Versioning](https://semver.org/spec/v2.0.0.html) for both repository-level and module-level changelogs.
