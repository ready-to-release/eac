# validate release-version

<!-- book:cmd validate release-version -->

## Validation Rules

- Must match `MAJOR.MINOR.PATCH` format (e.g., `1.2.3`).
- Must not have a `v` or `V` prefix.
- No leading zeros (except `0` itself).
