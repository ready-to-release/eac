## Version Formats

- **semver** -- `MAJOR.MINOR.PATCH` (e.g., `1.0.0`). A leading `v` prefix is stripped automatically.
- **calver** -- `YYYY.MMDD.HHMM` (e.g., `2025.0116.1430`).
