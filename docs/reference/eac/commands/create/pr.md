## How It Works

Creates pull request with AI-generated description:

- **Branch Analysis**: Analyzes all commits in current branch vs base
- **Change Summary**: Generates comprehensive summary of changes
- **Test Plan**: Creates test plan based on modified code
- **GitHub Integration**: Creates PR via GitHub API with generated content
- **Template Support**: Respects repository PR templates

Automates PR creation with detailed descriptions.
