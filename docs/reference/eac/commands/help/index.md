# help Commands

Display help information for commands.

## Commands in this Category

| Command           | Purpose                  |
| ----------------- | ------------------------ |
| [help](./help.md) | Display help information |

## Quick Examples

```bash
# Show general help
eac help

# Show help for a specific command
eac help build
```
