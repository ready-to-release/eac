# get commands

<!-- book:cmd get commands -->

## Output Fields

Each entry contains:

| Field         | Description                            |
| ------------- | -------------------------------------- |
| `command`     | Full command name (e.g. `get modules`) |
| `description` | Short description of the command       |

Parent commands (e.g. `get`, `show`) are automatically inferred from subcommand registrations.
