## Output Sections

A table with columns:

| Column      | Description                                       |
| ----------- | ------------------------------------------------- |
| Command     | Full command name (e.g., `show modules`, `build`) |
| Description | Short description of the command                  |

A footer row shows the total number of registered commands.
