# Core Commands

Core commands are top-level commands that don't fit into a specific category but provide essential functionality.

## Commands

| Command | Description |
|---------|-------------|
| [lint](./lint.md) | Lint one or more modules by moniker |

## Overview

These commands are invoked directly without a category prefix:

```bash
r2r eac lint              # Lint all modules
r2r eac lint eac-commands # Lint specific module
```
