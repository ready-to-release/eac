# release get-version

<!-- book:cmd release get-version -->

## Output

- Plain version string by default (e.g. `0.0.14`)
- Tag format with `--tag` (e.g. `clie/0.0.14`)
- JSON object with `--json` containing module, version, tag, date, and version_type fields
