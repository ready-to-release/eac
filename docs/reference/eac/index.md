# EAC Reference

Comprehensive reference documentation for the EAC (Everything as Code) extension.

## Overview

EAC is a comprehensive collection of commands designed to streamline **everything-as-code** workflows across your development lifecycle. It helps teams codify and version-control all aspects of software development—configuration, contracts, architecture, specifications, tests, security policies, and infrastructure.

**Key principle**: If it can be defined, it should be code. If it's code, it can be validated, versioned, and automated.
