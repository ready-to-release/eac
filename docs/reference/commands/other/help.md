# help

{{ page_breadcrumb() }}

## Overview

**Command**: `r2r eac help [command]`
**Purpose**: Display help information for commands
**Category**: [other](../categories/other.md)

## Syntax

```bash
r2r eac help [command]
```

## Examples

```bash
# Show general help
r2r eac help

# Show help for specific command
r2r eac help build

# Show help for subcommand
r2r eac help get modules

# Show help for category
r2r eac help show
```

## Output

Displays command syntax, description, options, and examples.
