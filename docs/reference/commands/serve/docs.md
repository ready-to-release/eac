# serve docs

{{ page_breadcrumb() }}

## Overview

**Command**: `r2r eac serve-docs [start|stop]`
**Purpose**: Start or stop MkDocs server
**Category**: [serve](../categories/serve.md)

## Syntax

```bash
r2r eac serve-docs [start|stop]
```

## Examples

```bash
# Start documentation server
r2r eac serve-docs start

# Opens at http://localhost:8000

# Stop server
r2r eac serve-docs stop
```
