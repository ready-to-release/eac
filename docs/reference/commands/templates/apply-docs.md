# templates apply-docs

## Overview

**Command**: `r2r eac templates apply-docs`
**Purpose**: Apply documentation templates with value replacements
**Category**: [templates](../categories/templates.md)

## Syntax

```bash
r2r eac templates apply-docs [options]
```

## Examples

```bash
# Apply documentation templates
r2r eac templates apply-docs

# Apply with specific module context
r2r eac templates apply-docs --module src-auth
```
