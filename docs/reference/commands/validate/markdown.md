## Overview

**Command**: `r2r eac validate markdown [file]`
**Purpose**: Validate markdown file syntax
**Category**: [validate](../categories/validate.md)

## Syntax

```bash
r2r eac validate markdown [file]
```

## Examples

```bash
# Validate all markdown
r2r eac validate markdown

# Validate specific file
r2r eac validate markdown README.md

# Validate directory
r2r eac validate markdown docs/
```
