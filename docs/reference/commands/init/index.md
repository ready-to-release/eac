# init Commands

Initialize EAC project configuration.

## Commands in this Category

| Command | Purpose |
|---------|---------|
| [init](./init.md) | Initialize EAC project configuration |

## Quick Examples

```bash
# Initialize a new EAC project
r2r eac init

# Initialize with specific options
r2r eac init --name my-project
```
