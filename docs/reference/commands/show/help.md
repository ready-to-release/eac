# show help

{{ page_breadcrumb() }}

## Overview

**Command**: `r2r eac show help [command]`
**Purpose**: Display help information for commands
**Category**: [show](../categories/show.md)

## Syntax

```bash
r2r eac show help [command]
```

## Examples

```bash
# Show all commands
r2r eac show help

# Show command help
r2r eac show help build

# Or use --help flag
r2r eac build --help
```
