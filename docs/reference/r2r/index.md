# R2R CLI Reference

Technical reference for the R2R CLI framework.

## What is R2R CLI?

R2R (Ready to Release) is a cross-platform CLI framework for containerized workflow execution. It provides a foundation for building modular command-line tools with support for Docker-based workflows, extension systems, and template management.
