# Tutorials

Step-by-step guides to help you get started with clie and Everything-as-Code workflows.

## Getting Started

**Goal:** Get clie installed, understand the fundamentals, and create your first extension

Start here if you're new to clie and Everything-as-Code:

[Getting Started](./getting-started/index.md) - Complete setup and fundamentals

- [Quick Start](./getting-started/quick-start.md) - Install clie CLI, initialize configuration, install EAC extension
- [Understanding Configuration Files](./getting-started/configuration-files.md) - Learn about `.clie/` and `.eac/` configuration files
- [Creating Your First Extension](./getting-started/creating-your-first-extension.md) - Build a custom clie extension from scratch

!!! tip "New to clie?"

    The Quick Start guide walks you through the complete setup:

    1. Install clie CLI binary
    2. Initialize clie configuration (`clie init`)
    3. Install EAC extension (`clie install eac`)
    4. Configure EAC (`eac init`)

See [CLI vs Extensions](../reference/eac/architecture/cli-integration.md) to understand the two-tier architecture.
