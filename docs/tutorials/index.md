# Tutorials

Step-by-step guides to help you get started with EAC and Everything-as-Code workflows.

## Getting Started

**Goal:** Get EAC installed, understand the fundamentals, and start automating

Start here if you're new to EAC and Everything-as-Code:

[Getting Started](./getting-started/index.md) - Complete setup and fundamentals

- [Quick Start](./getting-started/quick-start.md) - Install the EAC CLI, configure your project, run your first commands
- [Understanding Configuration Files](./getting-started/configuration-files.md) - Learn about `.eac/` configuration files

!!! tip "New to EAC?"

    The Quick Start guide walks you through the complete setup:

    1. Install the `eac` CLI binary
    2. Initialize EAC configuration (`eac init`)
    3. Explore available commands (`eac help`)
    4. Run your first build and test

See [CLIE Extension Host](../reference/clie/index.md) if you need containerized execution via Docker.
